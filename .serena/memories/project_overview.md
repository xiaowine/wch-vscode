TypeScript VS Code extension for WCH MounRiver Studio projects. It detects supported projects in the current workspace, parses project metadata/XML, generates cpptools configuration, exposes a sidebar overview/files tree, and adds status bar actions for Clean, Clean Build, and Build along with current project/MCU info. Main entrypoint is src/extension.ts. Key areas: src/build for build/clean resolution and tasks, src/sidebar for tree providers, src/models for parsed project models, and projectDetection/projectModelBuilder/xmlParser for discovery and parsing.
